# 按品牌检索知识：运营说明

## 适用范围

本功能统一任务、内容简报和批量导入的知识范围。不是商品图片/价格导入器，也不负责判断新品或热销。

## 选择方式

后台入口：

- 创建任务：`/geo_admin/tasks/create`。
- 内容简报：`/geo_admin/content-briefs`，创建后进入详情查看“匹配知识”和证据。
- Excel 批量导入：`/geo_admin/bulk-content-import`，先下载新版模板。

新建时使用“Automatic brand evidence”（品牌自动匹配），选择品牌一级目录。仅有一个知识来源站点时自动带出；多来源时明确选择。可选子目录包含其后代，留空表示该品牌和来源站点下的全部目录。

知识来源站点是商城或资料来源，不是文章最终发布的 WordPress/Shopify 渠道。切换发布渠道不能扩大知识范围。

旧任务保留“手动知识库”兼容模式，仍支持原来的明确知识库列表。切换为品牌模式后不再使用旧列表。

## 证据检索

使用主题、核心问题与可用关键词检索；不要求先给每份知识绑定关键词。只接受相同品牌、来源站点和语言下，已审核、active、允许生成且在有效日期范围内的资料。

初版采用本地词法相关性召回，未启用未经校准的向量独立命中，不增加检索模型 API 调用。语义改写、词形变化可能漏召回；可优化选题关键词，或在同一范围内手工补选证据。

默认最多 12 个完整片段、合计 24,000 字符。系统去重、排序并限制候选数量；出现候选上限提示时，可缩小子目录或明确查询。过长片段需要重新切分，不会截断政策句子后直接作为证据。

匹配到片段不代表整个问题都有充分证据。例如只命中“不要把退货寄到办公地址”，不能据此编造退款期限。正文仍需经过既有质量门禁。

## 简报与生成

查看匹配来源，按需补选或排除片段。手工补选区按标题和知识库名称列出同范围最多 100 个可用片段，超出时有提示，并提供高级 ID 补选。提交生成时会重新校验资料状态；已停用、越界或过期的旧预选会报错。

无可用证据时停止正文生成并提示“该品牌内证据不足”。不会跨品牌、跨来源站点或跨语言补资料，也不会自动放开未审核知识。

生成运行保存当次证据正文、来源和范围快照。同一次幂等重试复用原快照；需要采用更新知识时，应创建新的生成运行。

如果传统生成任务已保存品牌证据快照，失败后再把任务改为手动知识模式或切换生成引擎，旧运行会明确拒绝重试；请使用新配置创建新的运行。不能一边沿用旧审计，一边换用另一套资料生成。

## Excel 导入

请重新下载模板。新模板使用 brand，另可填写 directory、knowledge_site；复制参考表中的稳定 key 或带 key 的显示值。site 仍表示发布渠道，与 knowledge_site 不同。

旧 knowledge_base 模板仍可使用兼容模式。不要在同一行同时填写 brand 和 knowledge_base。名称重复时必须使用可唯一识别的值；导入校验失败会给出行号，不会部分创建任务。

## 排查证据不足

1. 核对品牌、来源站点、语言和子目录。
2. 检查资料是否 reviewed、active、generation_eligible。
3. 检查生效日期和复核到期日期。
4. 检查正文切片是否存在、是否确实回答该主题。
5. 必要时整理或审核资料，不要为了让任务通过而批量放开旧知识。
